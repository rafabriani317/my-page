# My Page

Página web personal hecha con HTML y CSS, como práctica de maquetación y estilos.

## Tecnologías

- HTML5
- CSS3

## Cómo empezar

1. Cloná el repositorio
2. Abrí el archivo index.html en tu navegador

## Colaboración

El proyecto sigue un flujo de trabajo basado en Feature Branching: cada mejora se desarrolla en una rama propia, se publica en GitHub y se integra a la rama principal mediante un Pull Request, después de revisar los cambios. Los cambios se registran con commits descriptivos. La última mejora agregó una tabla de habilidades e idiomas a la página `who-i-am`.
